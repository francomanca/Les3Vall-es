# 3 Vallées Ski Trip · 2027 — Group Itinerary

A single-page, self-contained itinerary for a group ski week in the **3 Vallées (600 km)** with
[Travelex.si](https://travelex.si), travelling **by plane** (Budapest → Torino).

It includes:

- Flight & transfer logistics (WizzAir, luggage drop-off, transfer times)
- Discounts (early-booking, returning-customer, group-organiser, 3-Vallées pass extension)
- A comparison of the three residences (location, nightlife, dining, amenities, ski access)
- An **interactive price estimator** — pick a group size (6–14) and a week, and it lists every valid
  room combination per residence with per-person and group all-in prices
- A final recommendation

## Run locally

It's a static site — just open `index.html` in a browser. No build step, no dependencies.

## Deploy on Vercel

1. Push this repo to GitHub (already the case if you're reading this there).
2. On [vercel.com](https://vercel.com) → **Add New… → Project** → import this repository.
3. Framework preset: **Other**. No build command, output directory is the repo root.
4. Deploy. Every push to `main` redeploys automatically.

## Data & disclaimer

Prices are sourced from travelex.si (3-Völgy accommodation & flight pages, plane view) as of July 2026.
Package € prices already include the early-booking discount, the local 6-day ski pass, 7 nights, airport
transfer and luggage transport — the flight and the €45 3-Vallées pass extension are separate. WizzAir fares
are dynamic and will rise. Currency conversion ≈ 400 Ft/€. **Not an official quote** — confirm with Travelex.
